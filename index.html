分配连续空间，使 top 与 base 重合。

看这里 点击上方任一操作，代码窗口会把正在执行的语句逐行高亮。

顺序栈：一句话抓住 top

base 固定不动；空栈时 base == top。每次入栈先写 *top = e，再执行 top++。

链栈：S 就是栈顶

没有头结点，S 直接指向栈顶结点。入栈执行 p->next = S; S = p;，三步完成头部插入。

共同规则：后进先出

两种实现只在存储方式和指针操作上不同；受限的插入、删除都发生在栈顶，因此访问顺序始终是 LIFO。

比较项 顺序栈 链栈
空栈条件 S.top == S.base S == NULL
满栈处理 S.top - S.base == S.stacksize，可报错或扩容 理论与动态内存有关；按需申请新结点
入栈核心 *S.top++ = e; p->next = S; S = p;
出栈核心 e = *--S.top; p = S; S = S->next; delete p;
