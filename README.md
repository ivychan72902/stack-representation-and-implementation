# 3.3 栈的表示与实现

交互式演示顺序栈和链栈的初始化、入栈、出栈与取栈顶元素。页面将指针移动、结点增删和 C/C++ 伪代码逐行同步展示，适合课堂讲解与自学。

## 在线演示

https://ivychan72902.github.io/stack-representation-and-implementation/

## 功能

- 顺序栈：演示 `base`、`top`、栈空与栈满条件
- 链栈：演示头指针 `S`、结点插入与删除
- 入栈、出栈、取栈顶元素
- 动画与代码高亮同步
- 桌面端和移动端响应式布局

## 本地运行

直接用浏览器打开 `index.html`，无需安装依赖或启动服务器。
